# Product
<!-- impeccable:product-schema 1 -->
## Platform
web
## Stack
Delegated by the user's request for an efficient, self-sufficient build: static HTML, CSS and ES modules, no runtime dependencies or backend. GitHub Pages deployment target.
## Users
Two to four people sharing a mobile phone for a golf card game.
## Product Purpose
Secretly plan shots, pass the phone, then reveal and resolve simultaneous play. Complete a round with automatic scoring.
## Constraints
Zero monthly infrastructure cost; finite 104-card deck with discard recycling; readable rules, sources, architecture and flowcharts. Standalone offline-capable web app. No accounts or remote multiplayer required.
## Evidence
Official site, tutorial transcript and public product photographs. Detailed provenance and inferred rules in docs/RULES.md. Original card artwork is not bundled.
## Decisions
User delegated design and implementation. House edition explicitly discloses inferred composition, scoring and adapted reaction windows. Mobile handoff privacy is a social screen cover, not protection from browser developer tools.
